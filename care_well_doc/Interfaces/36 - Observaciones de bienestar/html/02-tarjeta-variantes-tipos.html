Hoja de referencia — WellbeingObservationRow
Las 4 combinaciones tipo × severidad × categoría definidas en la especificación funcional, dentro del mismo contenedor WellbeingObservationsCard. Esta hoja no representa un estado real simultáneo (es poco probable que las 4 alertas coexistan para la misma persona); es material de referencia visual para implementación.

Ícono de fila (forma + color) = categoría · fondo/borde de fila = severidad · etiqueta de texto (“Atención”/“Informativa”) = redundancia accesible, nunca se comunica el estado solo por color.

La etiqueta gris pequeña tipo: ... es solo anotación de esta hoja de referencia para trazabilidad con la especificación funcional — no se muestra en la UI real (el usuario final no necesita ver el identificador técnico del tipo de alerta).
